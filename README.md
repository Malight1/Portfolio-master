## Getting Started

Requires `node.js` and `git`.

1. Install dependencies: `npm install`
2. Start the dev server: `npm start`, then open [http://localhost:3000](http://localhost:3000)
3. Production build: `npm run build`

## Editing Content

- Projects: `src/components/Projects/Projects.js` (screenshots in `src/Assets/Projects/`)
- Skills and tools: `src/components/About/Techstack.js` and `Toolstack.js`
- Resume: replace `src/Assets/Mubarak_General_Resume_ATS.pdf`
